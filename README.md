# DirectorDesk

Director Desk is a desktop application to control OBS Studio and ONVIF IP cameras.

The app is free to download and includes optional in-app subscription to Pro features.

## ✨ Features

See all functions and features at directordesk.pro

---

## 💻 System Requirements

- Windows 10 or later
- OBS Studio 28+ recommended
- ONVIF Profile S

---

## 📦 Installation

1. Download the latest release.
2. Run Director Desk.exe.
3. Install time <2min

---

## 🔐 Security

This software does not collect personal data without user consent.

If your browser or Windows shows a warning, this is due to the app not yet being code signed. The file is safe and published only via this official GitHub repository.
